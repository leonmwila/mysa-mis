# MYSA MIS User Manual

## 1. Purpose

This manual explains how to use the core modules in the MYSA MIS system and how IT staff can create and manage users.

The system currently includes the following core areas:

- Youth Tracking & Empowerment
- Artist Tracking & Analytics
- Sports Tracking & Analytics
- Associations & Organizations
- Venues Management
- Event & Program Management
- Teams and Groups Management
- User Management
- Company as Association / Organization

## 2. General Navigation

After logging in, use the main app menu to open a module. Each module has its own dashboard, list views, forms, and reporting menus.

Common actions used across modules:

- Create: add a new record.
- Edit: update an existing record.
- Save: store changes.
- Discard: cancel changes.
- Search: find records using filters.
- Group By: summarize records by category.
- Favorites: save reusable filters.

## 3. Core Module Overview

### 3.1 Youth Tracking & Empowerment

Purpose:

- Manage youth profiles, applications, empowerment programs, achievements, and analytics.

Typical tasks:

- Register youth profiles.
- Process CDF or empowerment applications.
- Track youth programs and participation.
- Review the youth dashboard for totals and trends.

Main menu areas:

- Dashboard
- Youth Profiles
- Applications
- Achievements
- Programs & Activities
- Zones
- Analytics & Reports

### 3.2 Artist Tracking & Analytics

Purpose:

- Manage artists, performance records, achievements, zones, and arts analytics.

Typical tasks:

- Register artists.
- Record performances and ratings.
- Track awards and achievements.
- Review analytics for performance and category distribution.

Main menu areas:

- Dashboard
- Artists
- Performances
- Achievements
- Zones
- Analytics
- Reports

### 3.3 Sports Tracking & Analytics

Purpose:

- Manage athletes, sports performance metrics, medals, zones, associations, and analytics.

Typical tasks:

- Register athletes.
- Record performance metrics.
- Track medals and achievements.
- Review the sports dashboard for participation and performance summaries.

Main menu areas:

- Dashboard
- Athletes
- Sports Zones
- Performance Metrics
- Achievements
- Quick Actions
- Reports & Analytics

### 3.4 Associations & Organizations

Purpose:

- Maintain a central registry of associations and organizations used by youth, arts, and sports modules.

Typical tasks:

- Create associations.
- Mark whether an association belongs to sports, arts, or youth.
- Reuse the same association across modules where applicable.

### 3.5 Venues Management

Purpose:

- Store shared venue information used by programs, events, arts activities, youth activities, and sports activities.

Typical tasks:

- Create and edit venue records.
- Record capacity, contacts, and availability.
- Reuse venues across multiple modules.

### 3.6 Event & Program Management

Purpose:

- Manage events, programs, participants, results, and achievement integration.

Typical tasks:

- Create programs and events.
- Register participants.
- Record results.
- Link achievements to events and programs.

### 3.7 Teams and Groups Management

Purpose:

- Manage sports teams and artist groups or bands.

Typical tasks:

- Create a team or group.
- Add members.
- Track group participation.
- Record team or group achievements.

### 3.8 Company as Association / Organization

Purpose:

- Allow companies to act as associations or organizations in the system.

Typical tasks:

- Mark a company as an association, organization, or institution.
- Assign domain usage such as sports, arts, or youth.
- Use the company as a logged-in organizational profile where required.

## 4. User Management for IT Staff

The User Management module is intended for IT administrators and system officers.

### 4.1 Create a User Profile

1. Open **User Management**.
2. Click **Profiles**.
3. Click **Create**.
4. Select the linked Odoo user in **User**.
5. Enter the staff member’s **National ID**, **Phone**, **Department**, **Council**, and **Role**.
6. Set the **Status** field.
7. Save the record.

### 4.2 Create a New Odoo User for an IT Role

Use this when a new IT staff member needs access to the system.

1. Open the main Odoo settings or Users menu.
2. Click **Create**.
3. Enter the user’s name, email, and login details.
4. Assign the correct access rights.
5. For IT administration, assign the **User Administrator** group if the person should manage users.
6. If the person only supports operational user setup, assign the **Youth/Arts Officer** group instead.
7. Save the user.
8. Return to **User Management > Profiles** and link the new Odoo user to a profile record.

### 4.3 IT Role Guidance

- Use **User Administrator** for system setup, access control, and user administration.
- Use **Youth/Arts Officer** for operational staff who manage records but should not control security settings.
- Only assign administrative access to trusted staff.

## 5. Typical Workflows

### 5.1 Youth Workflow

1. Create or open a youth profile.
2. Submit or review an application.
3. Assign the youth to a program or zone.
4. Track achievements and reports from the dashboard.

### 5.2 Artist Workflow

1. Create an artist profile.
2. Record performances.
3. Track awards or achievements.
4. Review analytics for progress and category trends.

### 5.3 Sports Workflow

1. Create an athlete record.
2. Assign zone and association details.
3. Record performance metrics and medals.
4. Review the sports dashboard and reports.

### 5.4 Event Workflow

1. Create a program or event.
2. Add participants.
3. Record results and achievements.
4. Review outputs in reporting screens.

## 6. Practical Tips

- Use dashboards first when checking overall status.
- Keep associations and venues centralized so data stays consistent across modules.
- Create the user profile after creating the Odoo account.
- Use filters and group by options for reporting instead of manual counting.
- Make sure the IT role is assigned only when needed.

## 7. Support Information

If you are unsure which module to use:

- Youth matters belong in Youth Tracking & Empowerment.
- Artist records belong in Artist Tracking & Analytics.
- Athlete and medal records belong in Sports Tracking & Analytics.
- Common institutions belong in Associations & Organizations.
- Venue records belong in Venues Management.
- Events and programs belong in Event & Program Management.
